# Manuales técnicos

Documentación para desarrolladores que quieran entender cómo está construida Glosa, configurar su entorno de desarrollo o contribuir al proyecto.

Está redactada para cualquier nivel de experiencia — un desarrollador junior debería poder seguir los pasos sin ayuda externa.

## Contenido

| # | Documento | Descripción |
|---|-----------|-------------|
| 01 | [Arquitectura](./01-arquitectura.md) | Cómo está organizado el sistema y por qué |
| 02 | [Entorno de desarrollo](./02-entorno-desarrollo.md) | Cómo configurar tu máquina para trabajar en el proyecto |
| 03 | [Estructura del código](./03-estructura-codigo.md) | Cómo está organizado el código fuente |
| 04 | [Almacenamiento](./04-almacenamiento.md) | Cómo funciona la persistencia de datos |

---

## ¿Por dónde empezar?

Si quieres contribuir, empieza por [Entorno de desarrollo](./02-entorno-desarrollo.md) para tener todo corriendo en tu máquina, y luego lee [Estructura del código](./03-estructura-codigo.md) para orientarte.

Si quieres entender decisiones de diseño, empieza por [Arquitectura](./01-arquitectura.md).
