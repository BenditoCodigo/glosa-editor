# Organizar con carpetas

Este documento explica cómo usar carpetas para mantener tus notas organizadas.

---

## Crear una carpeta

Haz clic en **Nueva carpeta** desde cualquier vista del explorador. Escribe un nombre descriptivo y confirma. La carpeta se crea dentro del nivel donde te encuentras.

---

## Navegar entre carpetas

- **Doble clic** en una carpeta para entrar y ver su contenido
- Usa las **migas de pan** en la parte inferior para volver a niveles anteriores
- El **panel lateral** también muestra las carpetas del nivel actual

---

## Opciones de carpeta

Cada tarjeta de carpeta tiene un botón de tres puntos (⋮) que aparece al pasar el cursor. También puedes hacer **clic derecho** sobre la tarjeta. Las opciones disponibles son:

### Agregar a favoritos

Marca la carpeta como destacada. Las carpetas favoritas aparecen en el panel lateral con un ícono especial para encontrarlas rápido.

### Renombrar

Cambia el nombre visible de la carpeta. Si estás usando almacenamiento en el sistema de archivos, el nombre de la carpeta en disco puede ser diferente al nombre que ves en la aplicación — esto es normal.

### Eliminar

Borra la carpeta y todo su contenido (notas y subcarpetas). La aplicación te pedirá confirmación antes de proceder. Esta acción no se puede deshacer.

---

## Vista dentro de una carpeta

Cuando estás dentro de una carpeta, verás:

- El **nombre de la carpeta** como título, con botones de acción (favorito, renombrar, eliminar)
- Las **subcarpetas** que contenga (si las hay)
- Las **notas** almacenadas en esa carpeta

---

## Consejos de organización

- Usa nombres cortos y descriptivos para las carpetas
- No crear demasiados niveles de profundidad — una o dos subcarpetas es suficiente para la mayoría de casos
- Marca como favorito las carpetas que uses todos los días
- Si una carpeta crece mucho, considera dividirla en subcarpetas temáticas
